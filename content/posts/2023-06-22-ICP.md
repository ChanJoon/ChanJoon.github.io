## Iterative Closest Point (ICP)
### Kabsch algorithm
the rotation of P into Q starts with two sets of paired points, P and Q.
$$\begin{bmatrix} x_1 && y_1 && z_1 \\ x_2 && y_2 && z_2 \\ ... && ... && ... \\ x_N && y_N && z_N \end{bmatrix}$$
Three steps:
	1. a **translation**
	2. the **computation of a covariance matrix**
	3. **the computation** of the optimal rotation matrix

#### Translation
sets of coordinates translated to coincides their centroid with the origin of the coordinate system.

#### Computation of the covariance matrix

$$
\\H = P^TQ
$$

or, summation notation

$$
H_{ij} = \sum^N_{k=1}P_{ki}\ Q_{kj}
$$

$\\H$ is a cross-covariance matrix when $\\P$ and $\\Q$ are seen as data matrices

#### Computation of the optimal rotation matrix
the optimal $\\R$ based on the matrix formula

$$
\\R = (H^TH)^{1/2}H^{-1}
$$

(but if case of $\\H$ not having an inverse, this solution becomes complicated)
If SVD available, the optimal rotation $\\R$ can be calculated
1. calculate the SVD of the covariance matrix $\\H$

$$
\\H = \\U\Sigma\\V^T
$$

2. decide whether we need to correct our rotation matrix to ensure a right-handed coordinate system
$$
\\d = \\sign({\det(\\V\\U^T)})
$$

3. calculate optimal rotation matrix $\\R$
$$
\\R = \\V \begin{bmatrix} 1 && 0 && 0 \\ 0 && 1 && 0 \\ 0 && 0 && d \end{bmatrix} \ \\U^T
$$

### Orthogonal Procrustes problem
= a matrix approximation
one is given two matrices $\\A$ and $\\B$ and asked to find an orthogonal matrix $\ohm$ which most closely maps $\\A$ to $\\B$.

$$
\\R = \arg\min_{\ohm}\|\ohm\\A-\\B\|_F\ \text{subject to}\ \ohm^T\ohm=\\I
$$
