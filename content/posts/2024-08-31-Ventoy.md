# Ventoy

[Ventoy 공식 사이트](https://www.ventoy.net/en/index.html)

다운로드 [링크](https://www.ventoy.net/en/download.html) 에 접속하면 sourceforce 를 통해 다운하도록 되어 있다. 다운로드가 잘 안되는 경우, `wget` 을 이용하여 직접 tarball 파일을 받을 수 있다.

```
wget https://download.sourceforge.net/ventoy/v1.0.99/ventoy-1.0.99-linux.tar.gz
tar xvf ventoy-1.0.99-linux.tar.gz
cd ventoy-1.0.99
./VentoyGUI.x86_64
```

OS 에 따라 실행하는 GUI 가 다르므로 자세한 내용은 Documentation 을 확인한다.

GUI 를 실행하면 모습은 아래와 같다.

![[VentoyGUI.png]]

이후, 부팅Disk 로 만들 USB 를 선택해주고 설치하면 끝이다. 주의할 점은, 포맷이 반드시 수행되니 중요한 내용이 있으면 옮겨두는 것이 좋다.

그리고는 iso 파일을 USB 아무 위치에 위치시키면 부팅Disk 가 만들어진다.
