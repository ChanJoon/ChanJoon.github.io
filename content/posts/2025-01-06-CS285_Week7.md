# Lecture 7: Value Function Methods

이전 시간에는 [[2024-03-18-CS285_Week6|Actor-Critic]] 에 대해 배워보았다.

## Part 1

### Can we omit policy gradient completely?

Value function $V^\pi$ 는 어떤 $\mathbf{s}_t$ 가 가장 좋은지 알려주기 때문에, 단순히 더 큰 $V^\pi$ 를 얻는 action $\mathbf{a}_t$ 를 선택하게 하면 되므로 명시적인 policy neural network 가 필요하지 않을 수 있다.

![[CS285_Lec7_omitPG.png]]

수식적으로 표현하면 $A^\pi$ 를 가장 최대화하는 action $\mathbf{a}_t$ 를 선택하자는 것이다. 이런 방식은 선택된 어떤 $\mathbf{a}_t$ 보다 같거나 좋게 되고, policy $\pi(\mathbf{a}_t|\mathbf{s}_t)$ 에 상관없이 가장 좋은 $\mathbf{a}_t$ 를 선택하게 된다.

![[CS285_Lec7_AC.png]]

이전의 Actor-Critic 알고리즘과 비교해보면 더이상 policy gradient 를 수행할 필요 없이 policy improvement 를 수행할 수 있다.

### Policy iteration

^c50d77

![[CS285_Lec7_policy_iteration.png]]

전체 알고리즘을 정리하면 위의 그림과 같다. 여기서의 문제는 $\mathbf{A}^\pi(\mathbf{s},\mathbf{a})$ 가 어떤 것이 가장 좋은지 어떻게 평가할 것인가 이다.

이전에 advantage function $\mathbf{A}^\pi(\mathbf{s},\mathbf{a})$ 를 평가한 방식을 보면 $\mathbf{V}^\pi(\mathbf{s})$ 를 평가하면 된다.

### Dynamic programming

![[CS285_Lec7_DP.png]]

위와 같은 tabular MDP 에서는 transition probability $p(\mathbf{s}'|\mathbf{s},\mathbf{a})$ 를 알기 때문에 iteration 을 통해 optimal policy 를 쉽게 구해낼 수 있다.

### Policy iteration with dynamic programming

![[CS285_Lec7_policy_iteration_DP.png]]

Tabular MDP 환경에서는 위 알고리즘 대로 policy evaluation 과 iteration 을 각 state 마다 수행하면 된다.

### Even simpler dynamic programming

![[CS285_Lec7_even_simpler_DP.png]]

우리가 policy evaluation 을 수행할 때 $\arg\max_{\mathbf{a}_t} {A}^\pi(s_t, a_t)$ 를 계산하고 있다. 이 때, 우리는 $\mathbf{a}_t$ 를 찾고 있기 때문에 이와 관련되어 있지 않은 항인 $-{V}^\pi(\mathbf{s})$ 는 지워져도 관계 없다.

따라서 $\arg\max_{\mathbf{a}_t} {A}^\pi(s_t, a_t)=\arg\max_{\mathbf{a}_t} {Q}^\pi(s_t, a_t)$ 가 성립함을 알 수 있고, 이를 구하는 것이 더 쉬워진다. ($V^\pi(\mathbf{s})$ 를 구할 필요가 없어진다.)

$\arg\max_{\mathbf{a}}Q(\mathbf{s},\mathbf{a})$ 가 policy 를 구하는 것과 같으므로 policy 를 따로 구할 필요 없이 $\max_{\mathbf{a}}Q(\mathbf{s},\mathbf{a})$ 를 이용해서 value $V(\mathbf{s})$ 를 바로 구할 수 있다.

위 사진을 보면 $Q(\mathbf{s}, \mathbf{a})$ 테이블을 구성해서 $\max_{\mathbf{a}} Q$ 로 $V(\mathbf{s})$ 를 얻은 후 이를 반복해서 알고리즘을 수행할 수 있음을 알 수 있다.

## Part 2: Fitted Value Iteration & Q-Iteration

### Fitted value iteration

^3ef84c

![[CS285_Lec7_fitted_value_iteration.png]]

이전과 달리 더 큰 환경에서 신경망을 활용하는 경우를 생각해보자.

이러한 경우 state space 의 dimension 이 매우 커지기 때문에 연산이 매우 커짐을 알 수 있다. 그래서 function approximator 를 사용한다. 이전 [[2024-03-18-CS285_Week6|6강]] 에서 다루었듯이 neural network $V_\phi : \mathcal{S} \rightarrow \mathbb{R}$ 를 사용한다.

### What if we don't know the transition dynamics?

![[CS285_Lec7_fitted_value_iteration_model_free.png]]

슬라이드에서 볼 수 있듯이 빨간 밑줄에서 transition dynamics 를 알아야 $\max$ 를 구할 수 있다.

그래서 $V^\pi$ 를 평가하는 대신 $Q^\pi$ 를 평가하면 이러한 문제를 피할 수 있다. 이전에 [[#^c50d77|Policy iteration]] 와 비교해보면, 수식을 대체해서 사용된 것을 알 수 있다. $\mathbb{E}$ 를 계산할 때도 $p(\mathbf{s}'|\mathbf{s},\mathbf{a})$ 에서 샘플하기 때문에 더이상 policy $\pi$ 는 중요하지 않음을 알 수 있다.

그래서 수식을 약간 바꾼 것처럼 보이지만 transition dynamics 를 알지 못해도 policy iteration 을 수행할 수 있게 된다.
