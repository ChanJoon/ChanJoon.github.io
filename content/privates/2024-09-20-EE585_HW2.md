### 1. Derive the system equation

**When the robot faces forward**

We have the coordinates transformation from Cartesian to Polar.

$$
\begin{align}
\rho &= \sqrt{\Delta{x}^2+\Delta{y}^2} \\
\alpha &= - \theta + \text{atan}(\frac{\Delta{y}}{\Delta{x}}) \\
\beta &= - \theta - \alpha
\end{align}
$$

Without loss of generality, We adopt the kinematics of a differential drive model as described in the EE585 lecture slides.

Let ${\alpha} \in I_1 = (-\frac{\pi}{2}, \frac{\pi}{2}]$, representing the angle between the $x$-axis fo the robots reference frame and the vector connecting the center of the axle of the wheels with the final position.

Based on the Cartesian coordinates provided in the lecture slides, the following relations hold.

$$
\begin{align}
\dot{x} &= v\cos\theta \\
\dot{y} &= v\sin\theta \\
\dot{\theta} &= \omega \\
\cos(\alpha + \theta) &= \frac{\Delta{x}}{\rho} = -\frac{x}{\rho} \\
\sin(\alpha + \theta) &= \frac{\Delta{y}}{\rho} = -\frac{y}{\rho} 
\end{align}
$$

By differentiating the coordinate transformation, we can get the system equation when the robot faces forward.

$$
\begin{align}
\dot{\rho}
&= \frac{2(x\dot{x} + y\dot{y})}{2\sqrt{\dot{x}^2+\dot{y}^2}}
= \frac{1}{\rho}(x\dot{x} + y\dot{y})
= \frac{1}{\rho}(x\cdot v\cos\theta+y\cdot v\sin\theta)\\
&= v(\cos\theta\cdot\frac{x}{\rho}+\sin\theta\cdot\frac{y}{\rho}) =-v(\cos\theta\cos(\alpha+\theta)+\sin\theta\sin(\alpha+\theta)) \\
& =-v\cos\alpha \\
\dot{\alpha} &= \{-\theta+\text{atan}(\frac{\Delta{y}}{\Delta{x}})\}'
= -\dot{\theta}+\frac{-y}{x^2+y^2}\cdot\dot{x}+\frac{x}{x^2+y^2}\cdot\dot{y} \\
&= -\omega + \frac{v\cos\theta}{\rho^2}\cdot\rho\sin(\alpha+\theta) + \frac{v\sin\theta}{\rho^2}\cdot(-\rho\sin(\alpha+\theta)) \\
&= - \omega + \frac{v}{\rho}(\cos\theta\sin(\alpha+\theta)-\sin\theta\cos(\alpha+\theta)) \\
&= -\omega + \frac{v}{\rho}\sin\alpha \\

\dot{\beta} &= -\dot{\theta}-\dot{\alpha} = -\omega +\omega + \frac{v}{\rho}\sin\alpha \\
&= -\frac{v}{\rho}\sin\alpha
\end{align}
$$

Now we can represent the derivation into matrix equation as follows.

$$
\begin{align}
\begin{bmatrix}
\dot{\rho} \\
\dot{\alpha} \\
\dot{\beta}
\end{bmatrix}
=
\begin{bmatrix}
-\cos\alpha & 0 \\
\frac{\sin\alpha}{\rho} & -1 \\
-\frac{\sin\alpha}{\rho} & 0
\end{bmatrix}
\begin{bmatrix}
v \\ \omega
\end{bmatrix}
\end{align}
$$

**When the robot faces backward**

if $\alpha \in I_2 = (-\pi, -\frac{\pi}{2}] \cup (\frac{\pi}{2}, \pi]$, indicating the robots faces backward, we set $v_{back}=-v$ and derive the system equation as follows.

$$
\begin{align}
\begin{bmatrix}
\dot{\rho} \\
\dot{\alpha} \\
\dot{\beta}
\end{bmatrix}
=
\begin{bmatrix}
\cos\alpha & 0 \\
-\frac{\sin\alpha}{\rho} & 1 \\
\frac{\sin\alpha}{\rho} & 0
\end{bmatrix}
\begin{bmatrix}
v \\ \omega
\end{bmatrix}
\end{align}
$$

Note that the sign of $\omega$ in $\dot{\alpha}$ should also flips to ensure the correct rotational direction.

## 3. Discussion
The system’s stability is ensured when the characteristic polynomial of the ODE matrix has negative real parts, ensuring exponential convergence to the goal (assuming $\cos\theta\approx 1, \sim\theta\approx 1$).

This is guaranteed when the following conditions on the control gains hold: $k_\rho > 0; k_\beta < 0;$, and $k_\alpha - k_\rho > 0$. The robot’s motion in both the forward and backward configurations follows this reasoning.

Detailed proof is explained in the lecture slides.

As we can see in the first case(first column in the figure), which control gains are $k=(k_\rho, k_\alpha, k_\beta)=(2.0, 5.0, -2.0)$, the paths shows stable movement and finally reach the goal for both goal orientation angles, $\pi/2\ \text{or}\ \pi$.

This demonstrates the stability conditions

$$
k_\rho = 2.0 > 0; k_\beta = -2.0 < 0; k_\alpha - k_\rho = 3.0 > 0
$$

In contrast, the second column in the figure shows that the control gains $k=(k_\rho, k_\alpha, k_\beta)=(2.0, 2.0, -2.0)$ doesn't satisfy the stability conditions.

$$
k_\alpha - k_\rho = 0.0 \leq 0
$$

As a result, the robot diverges for both goal orientation angles.

```python
import numpy as np
import matplotlib.pyplot as plt

def normalize_angle_pi_to_pi(angle):
    return (angle + np.pi) % (2 * np.pi) - np.pi


class DifferentialDriveRobot:
    
    def __init__(self, init_state, theta_goal, control_gain, dt):
        self.init_state = init_state
        self.theta_g = theta_goal
        self.k_rho = control_gain[0]
        self.k_alpha = control_gain[1]
        self.k_beta = control_gain[2]
        self.dt = dt
        
        self.alpha = self.init_state[1] - np.pi
        self.model_type = None
        if -np.pi/2 < self.alpha <= np.pi/2:
            self.model_type = "front"
        else:
            self.model_type = "back"
            

    def get_input(self, rho, alpha, beta):
        if self.model_type == "front":
            # Forward orientation
            v = self.k_rho * rho
            omega = self.k_alpha * alpha + self.k_beta * beta
        elif self.model_type == "back":
            # Backward orientation
            v = - self.k_rho * rho
            alpha = normalize_angle_pi_to_pi(alpha - np.pi)
            beta = normalize_angle_pi_to_pi(beta - np.pi)
            omega = + (self.k_alpha * alpha + self.k_beta * beta)
            
        return v, omega
        
    def update(self, rho, alpha, beta, v, omega):
        rho -= v * np.cos(alpha) * self.dt
        alpha += ((v * np.sin(alpha) / rho) - omega) * self.dt
        beta -= (v * np.sin(alpha) / rho) * self.dt
        
        return rho, alpha, beta

    def simulate(self):
        # Initialize state arrays
        x = []
        y = []
        theta = []

        # Set initial conditions
        rho = self.init_state[0]
        alpha = self.init_state[1] - np.pi # Substract pi to transform global frame to local frame
        beta = self.theta_g - alpha

        epsilon = 1e-6
        theta_i = 0.0
        
        # Draw initial position in global frame
        x.append(rho * np.cos(-beta - self.theta_g))
        y.append(rho * np.sin(-beta - self.theta_g))
        theta.append(theta_i)

        while rho > epsilon:
            # Get control input
            v, omega = self.get_input(rho, alpha, beta)
                
            # Update state
            rho, alpha, beta = self.update(rho, alpha, beta, v, omega)
            theta_i += omega * self.dt
            
            x.append(rho * np.cos(-beta - self.theta_g))
            y.append(rho * np.sin(-beta - self.theta_g))
            theta.append(theta_i)

        return x, y, theta

def load_system_parameters():
    # System variables
    dt = 0.001
    
    unit_circle_radius = 0.05
    unit_circle_thetas = np.linspace(0, 2*np.pi, 8, endpoint=False)
    init_state = [[unit_circle_radius, unit_circle_theta] for unit_circle_theta in unit_circle_thetas]
    
    return dt, init_state

def draw_plot(axs, x_traj, y_traj, theta_traj, line_color, idx):
    plot_idx = [idx // 16, (idx // 8) % 2]
    axs[plot_idx[0], plot_idx[1]].plot(x_traj, y_traj, color=line_color[idx])
    axs[plot_idx[0], plot_idx[1]].grid(True)
    axs[plot_idx[0], plot_idx[1]].axis('equal')
    axs[plot_idx[0], plot_idx[1]].arrow(x_traj[0], y_traj[0], 0.002 * np.cos(theta_traj[0]), 0.002 * np.sin(theta_traj[0]),
                head_width=0.002, head_length=0.004, fc='black', ec='black', linewidth=0.2/5)
    axs[plot_idx[0], plot_idx[1]].arrow(x_traj[-1], y_traj[-1], 0.002 * np.cos(theta_traj[-1]), 0.002 * np.sin(theta_traj[-1]), 
                head_width=0.002, head_length=0.004, fc='black', ec='black', linewidth=0.2/5)
    

def main():
    # System variables
    dt, init_states = load_system_parameters()
    
    theta_goals = [np.pi / 2, np.pi]
    control_gains = [
        [2.0, 5.0, -2.0],
        [2.0, 2.0, -2.0],
        ] # [k_rho, k_alpha, k_beta]
    
    robots = [DifferentialDriveRobot(init_state, theta_goal, control_gain, dt)
              for theta_goal in theta_goals
              for control_gain in control_gains
              for init_state in init_states
            ]

    # Initialize plot
    fig, axs = plt.subplots(2, 2, figsize=(10, 6))
    line_color = plt.cm.viridis(np.linspace(0, 1, len(robots)))

    for idx, robot in enumerate(robots):
        # Simulate robot motion
        x_traj, y_traj, theta_traj = robot.simulate()

        # Plot trajectory
        draw_plot(axs, x_traj, y_traj, theta_traj, line_color, idx)
    
    for ax in axs.flat:
        ax.set_xlim(-0.06, 0.06)
        ax.set_ylim(-0.06, 0.06)
    axs[1, 0].set_xlabel("k = (2.0, 5.0, -2.0)", fontsize=25)
    axs[1, 1].set_xlabel("k = (2.0, 2.0, -2.0)", fontsize=25)
    axs[0, 0].set_ylabel("Goal rotation angle: pi / 2", fontsize=25)
    axs[1, 0].set_ylabel("Goal rotation angle: pi", fontsize=25)
    plt.tight_layout()
    plt.show()

if __name__ == "__main__":
    main()
```
